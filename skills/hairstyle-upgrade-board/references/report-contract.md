# 发型升级报告契约

## 最低内容

- 画布：横向 4:3；推荐 2400×1800 PNG。
- Before：原始照片，不得经过美化或改变发型。
- After：同一人物，仅改变发型相关视觉变量。
- 推荐区：恰好 4 个方案，每项包含名称、改变点、优势和可执行性备注。
- 避雷区：恰好 3 个方案，每项包含不推荐原因；语气轻微，不丑化人物。
- 执行指南：最佳发长、修剪重点、日常打理、维护周期、自然发色建议。
- 明确标签：`AI 模拟`、`视觉提案` 或等价表述。

## 事实分层

| 层级 | 可写内容 | 禁止写法 |
| --- | --- | --- |
| 用户提供 | 用户说想要的风格、限制和照片授权 | 把未说过的偏好当成事实 |
| 可见观察 | 当前长度、刘海状态、头发是否贴头皮 | 把观察写成医学或科学测量 |
| 设计建议 | 刘海方向、层次、发色、打理方法 | 保证一定显瘦、变年轻或适合所有人 |
| 未验证事项 | 维护周期、施工难度、成品效果 | 编造价格、时长、产品功效或治疗结果 |

## 输出状态

分别记录：素材是否可用、身份一致性是否通过视觉检查、报告是否成功渲染、是否人工复核、是否公开发布。Skill 验证通过不等于真实肖像生成成功，也不等于发型师施工验证。
